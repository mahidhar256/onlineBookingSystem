# Online Banking System

A **Java-based Online Banking System** with **MySQL database integration** to manage account creation, user authentication, and basic transaction operations.  

### 🚀 Features
- User Registration & Secure Login  
- Account Management (Balance tracking, updates)  
- JDBC connectivity with MySQL  
- Modular architecture (Model–Service–DB layers)  
- Built and executed in **VS Code** with MySQL Connector  

### 🛠️ Tech Stack
- Java  
- MySQL  
- JDBC  
- VS Code / Git
